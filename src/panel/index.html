medula

Let a coding agent read and change the state of the page you have open. There is no UI here: the agent is the UI.

Looking for the devtools connection…

1. Point your agent at the MCP endpoint

Streamable HTTP endpoint of this dev server (shared with the other devtools):

…
Claude Code 
…
.mcp.json / Cursor / Windsurf / VS Code 
…
Any running dev server (devframe connect)

One stdio server that discovers every running devframe dev server on this machine, so the port can change: 

{
  "mcpServers": {
    "devframe": { "command": "npx", "args": ["devframe", "connect"] }
  }
}

2. Read and change your app state

Open your app in the browser. medula finds Vue, Pinia, Vue Router, React, Svelte and Solid state automatically. No state registration is needed.

Ask your agent to call medula_help for the available tools, then read and change component state or Pinia stores. Tools appear while the app page is open.
