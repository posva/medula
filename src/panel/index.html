medula

Let a coding agent read and change the state of the page you have open. There is no UI here: the agent is the UI.

Looking for the devtools connection…

Streamable HTTP endpoint of this dev server (shared with the other devtools):

Any running dev server (devframe connect)

One stdio server that discovers every running devframe dev server on this machine, so the port can change: 

{
  "mcpServers": {
    "devframe": { "command": "npx", "args": ["devframe", "connect"] }
  }
}

2. Expose state from your app

Tools appear while a page of your app is open in the browser: medula_list-states, medula_get-state, medula_set-state, medula_patch-state, plus component tools for Vue, Pinia, Vue Router, React and Svelte. Call medula_help for the details. Expose extra state with the helpers: 

import { exposeState } from 'medula/client'

exposeState('cart', {
  description: 'Shopping cart items',
  get: () => cart,
  set: (value) => (cart = value),
})

See medula/vue, medula/react and medula/svelte for refs, stores and hooks.
