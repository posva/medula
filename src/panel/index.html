MCP DevTools

Any running dev server (devframe connect)

One stdio server that discovers every running devframe dev server on this machine, so the port can change: 

{
  "mcpServers": {
    "devframe": { "command": "npx", "args": ["devframe", "connect"] }
  }
}

2. Expose state from your app

Tools appear while a page of your app is open in the browser. Expose state with the framework helpers: 

import { exposeState } from 'mcp-devtools/client'

exposeState('cart', {
  description: 'Shopping cart items',
  get: () => cart,
  set: (value) => (cart = value),
})

See mcp-devtools/vue, mcp-devtools/react and mcp-devtools/svelte for refs, stores and hooks.
